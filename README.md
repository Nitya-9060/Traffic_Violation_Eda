# Traffic_Violation_Eda
It is an exploratory data analysis done on Indian traffic violation.Traffic violations have been occuring at an extreme extent in our day-to-day life.This data analysis shows different types of violations occured,penalties,gender wise differentiating etc.I have used certain libraries such as numpy,pandas,matplotlib,seaborn etc.


#Objectives of the data analysis:-

a)Different types of violation occured

b)Gender wise cateogories - which gender occured more violations

c)Different type of rule violation

d)Different types of vehicles  which violated the rules.
